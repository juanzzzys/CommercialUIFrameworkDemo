CommercialUIFrameworkDemo

一个用于 Unity 游戏客户端 / UI 开发学习与面试准备的个人实战项目。

项目目标：通过逐步实现 UI Framework、背包系统、对象池、虚拟化列表、EventBus、红点系统和性能分析，理解 Unity 客户端开发中的常见设计与优化思路。

 项目结构

Assets/
├── Art/          美术资源
├── Core/        全局/基础系统
├── Data/         数据定义
├── Prefabs/     可复用 Prefab
├── Scenes/       Unity 场景
├── Scripts/      普通业务脚本/功能脚本
└── UI/           UI 相关资源与脚本
